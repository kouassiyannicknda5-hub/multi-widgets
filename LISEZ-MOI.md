# Multi-Widgets (première version)

Plusieurs widgets déplaçables et redimensionnables (jusqu'à 10), chacun ouvrant une seule application.

## Utiliser sur le téléphone
1. Mettre le dossier sur un hébergement HTTPS (GitHub Pages, Render, Netlify…).
2. Ouvrir l'adresse dans Chrome (Android).
3. Menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).

## Tester sur ordinateur
Ouvrir index.html dans un navigateur (l'installation demande HTTPS).

## Contenu
- index.html : l'application
- manifest.json et sw.js : installation et mode hors ligne
- icons/ : icônes 192 et 512

## À savoir
Les tuiles sont des aperçus simulés. Le bouton « Ouvrir le site » ouvre la vraie version web.
Les fenêtres flottantes par-dessus les autres applications demandent un projet Android natif (étape suivante).
